Internal Architecture of 8085 Microprocessor:

The 8085 is an 8-bit microprocessor with a 16-bit address bus and 8-bit data bus. Its internal architecture consists of the following blocks:

1. Arithmetic & Logic Unit (ALU): Performs arithmetic (ADD, SUB, INC, DEC) and logical (AND, OR, XOR, CMP) operations on 8-bit data. It interacts with the accumulator and flag register.

2. Accumulator (A): An 8-bit register that is the primary working register. ALU operations use accumulator as one of the operands and result is stored here.

3. General Purpose Registers (B, C, D, E, H, L): Six 8-bit registers. They can be used in pairs (BC, DE, HL) as 16-bit registers for memory addressing.

4. Flag Register: Contains 5 flags – S (Sign), Z (Zero), AC (Auxiliary Carry), P (Parity), CY (Carry).

5. Program Counter (PC): 16-bit register. Holds the address of the next instruction to be fetched.

6. Stack Pointer (SP): 16-bit register. Points to the top of the stack in memory.

7. Instruction Register & Decoder: Holds the fetched opcode and decodes it to generate control signals.

8. Timing & Control Unit: Generates control signals (ALE, RD̄, WR̄, IO/M̄, S0, S1) for synchronizing operations.

9. Interrupt Control: Handles 5 hardware interrupts (TRAP, RST7.5, RST6.5, RST5.5, INTR).

10. Serial I/O Control: Contains SID (Serial Input Data) and SOD (Serial Output Data) lines for serial communication.

11. Bus Interface: The multiplexed AD0–AD7 bus carries both address (lower 8 bits) and data. ALE signal is used to demultiplex. A8–A15 are the upper address lines.

8255A – Programmable Peripheral Interface (PPI):

8255A is a general purpose programmable I/O device designed to transfer data between the microprocessor and peripheral devices.

Block Diagram Components:

1. Data Bus Buffer: 8-bit bidirectional, 3-state buffer that interfaces the 8255A with the system data bus. All data, control words, and status information pass through this buffer.

2. Read/Write Control Logic: Controls data flow direction (read or write). Inputs: CS̄, RD̄, WR̄, A0, A1, RESET.

3. Group A and Group B Control:
  • Group A: Controls Port A (PA0–PA7) and upper nibble of Port C (PC4–PC7)
  • Group B: Controls Port B (PB0–PB7) and lower nibble of Port C (PC0–PC3)

4. Port A (8 bits): Can be configured as input or output. Supports Mode 0, 1, 2.

5. Port B (8 bits): Can be configured as input or output. Supports Mode 0, 1 only.

6. Port C (8 bits): Can be used as I/O or as handshake/control signals for Port A and Port B.

Modes of Operation:
  • Mode 0 (Basic I/O): Simple I/O without handshaking. Ports A, B, C as input/output.
  • Mode 1 (Strobed I/O): Handshaking mode. Port C provides handshake signals.
  • Mode 2 (Bidirectional Bus): Only Port A. Bidirectional data transfer with handshaking.
  • BSR Mode: Bit Set/Reset mode for Port C individual bits.

Port Selection:
A1 A0 = 00 → Port A  |  01 → Port B  |  10 → Port C  |  11 → Control Register

8259A – Programmable Interrupt Controller (PIC):

8259A manages up to 8 interrupt requests simultaneously. Multiple 8259As can be cascaded to handle 64 interrupts.

Block Diagram Components:

1. Interrupt Request Register (IRR): Stores all pending interrupt requests from IR0–IR7.

2. In-Service Register (ISR): Records which interrupt is currently being serviced.

3. Interrupt Mask Register (IMR): Stores bits for masking (disabling) specific interrupt requests.

4. Priority Resolver: Determines highest priority interrupt from IRR while considering ISR and IMR.

5. Data Bus Buffer: Bidirectional 8-bit buffer for 8085 communication.

6. Read/Write Control Logic: Controls read and write operations.

7. Cascade Buffer/Comparator: Used when multiple 8259As are connected in master-slave configuration.

8. Control Logic: Generates INT signal to CPU and receives INTA̅ from CPU.

Operation Flow:
  • IR0–IR7 receive interrupt signals → stored in IRR
  • Priority Resolver selects highest priority (considering IMR)
  • INT pin goes HIGH → CPU sends INTA̅
  • IRR bit is reset, ISR bit is set
  • CPU reads vector byte from data bus
  • After service: EOI (End of Interrupt) resets ISR bit

Initialization: Requires 2–4 Initialization Command Words (ICW1–ICW4).
Operation Commands: 3 Operation Command Words (OCW1–OCW3).

📝 Model Answer
Addressing Modes of 8085:

An addressing mode specifies how the operand of an instruction is located.

1. Immediate Addressing Mode:
The data (operand) is part of the instruction itself.
MVI A, 32H → Load 32H directly into register A
LXI H, 2050H → Load 2050H directly into HL pair

2. Register Addressing Mode:
Operand is in a register.
MOV A, B → Copy content of B into A
ADD C → Add C to A

3. Register Indirect Addressing Mode:
Address of operand is stored in a register pair.
MOV A, M → Fetch data from memory location pointed by HL
LDAX B → Load A from address in BC pair

4. Direct Addressing Mode:
The 16-bit address of operand is given in the instruction.
LDA 2050H → Load A from memory address 2050H
STA 3000H → Store A at memory address 3000H

5. Implicit (Inherent) Addressing Mode:
Operand is implied in the opcode itself; no explicit address.
CMA → Complement A (A is implied)
RAL → Rotate A Left through Carry
NOP → No operation

Interfacing 4KB EPROM (2732) with 8085:

Given: 4KB EPROM, starting address = 0000H
End address: 0000H + 0FFFH = 0FFFH

Address Range Analysis:
4KB = 4 × 1024 = 4096 locations → needs 12 address lines (A0–A11)

Address lines:
A0–A11 → connected directly to EPROM address pins (A0–A11)
A12–A15 → used for chip select logic

For starting address 0000H:
Binary: A15=0, A14=0, A13=0, A12=0 → All high address lines are 0
→ Use a NAND/NOR gate: CE̅ = A15 + A14 + A13 + A12 (NOR gate output)
When A15–A12 = 0000, CE̅ = 0 → chip enabled

Connections:
  • AD0–AD7 (demultiplexed) → D0–D7 of EPROM
  • A0–A11 → A0–A11 of EPROM
  • IO/M̅ and RD̅ → OE̅ of EPROM (AND gate)
  • Chip Enable → derived from A12–A15

Note: Use 74LS138 decoder for multiple memory chips.

📝 Model Answer
Demultiplexing of AD0–AD7 in 8085:

The 8085 has a multiplexed address/data bus. Pins AD0–AD7 carry both lower 8-bit address (A0–A7) during the first half of T1, and data during T2 and T3.

Why Demultiplexing is Needed:
Since both address and data share pins, we must separate them before connecting to memory or peripherals.

Demultiplexing Circuit:
Uses a 74LS373 Latch (octal D-type latch):
  • AD0–AD7 → connected to inputs of 74LS373
  • ALE signal → connected to EN (Enable/Latch Enable) of 74LS373
  • When ALE = HIGH (during T1), address appears on AD0–AD7 → latched in 74LS373
  • Outputs of 74LS373 give stable A0–A7
  • When ALE = LOW, AD0–AD7 carries data → latch holds address

T-State Timeline:
T1: ALE=HIGH → A0-A7 on AD0-AD7 → Latch captures address
T2: ALE=LOW  → Data on AD0-AD7
T3: ALE=LOW  → Data read/write occurs

Timing Diagram of MVI A, 45H:

Instruction: MVI A, 45H — Move Immediate to Accumulator
Opcode: 3EH    Size: 2 bytes    Machine Cycles: 2 (Opcode Fetch + Memory Read)
T-States: 7 (4 + 3)

Machine Cycle 1 – Opcode Fetch (M1): 4 T-states
T1: ALE=1, A8-A15=PCH, AD0-AD7=PCL (address), IO/M̄=0
T2: ALE=0, RD̄=0, AD0-AD7=data (3EH opcode from memory)
T3: Data (3EH) sampled, PC incremented
T4: Instruction decoded, nothing on bus
Machine Cycle 2 – Memory Read (M2): 3 T-states
T1: ALE=1, A8-A15=PCH, AD0-AD7=PCL (next address)
T2: ALE=0, RD̄=0, AD0-AD7=data (45H operand)
T3: Data (45H) sampled, loaded to A register
Signal Summary:
  • ALE goes HIGH at T1 of each machine cycle to latch address
  • RD̄ goes LOW during T2-T3 for memory read
  • IO/M̄ = LOW (memory operation)
  • AD0–AD7 carries address during T1, data during T2-T3

Flag Register of 8085:

The flag register is an 8-bit register, but only 5 bits are used as flags:
Bit:  D7  D6  D5  D4  D3  D2  D1  D0
Flag:  S   Z   0  AC   0   P   1  CY
S – Sign Flag (D7): Set to 1 if the result of an operation is negative (MSB = 1). Used in signed arithmetic.

Z – Zero Flag (D6): Set to 1 if the result of an operation is zero. Used in loop control and conditional jumps (JZ, JNZ).

AC – Auxiliary Carry Flag (D4): Set to 1 if there is a carry from bit 3 to bit 4. Used for BCD arithmetic (DAA instruction).

P – Parity Flag (D2): Set to 1 if result has even number of 1s (even parity). Set to 0 for odd parity.

CY – Carry Flag (D0): Set to 1 if an arithmetic operation generates a carry out of the MSB or a borrow. Used in multi-byte arithmetic.

Hardware Interrupts (5 total, priority order):

Maskable, edge-triggered. Vector address: 003CH. Masked by SIM instruction.

3. RST 6.5 – Priority 3:
Maskable, level-triggered. Vector address: 0034H.

4. RST 5.5 – Priority 4:
Maskable, level-triggered. Vector address: 002CH.

5. INTR – Priority 5 (Lowest):
Maskable, level-triggered. Non-vectored; CPU sends INTA̅, then gets vector from external hardware.

Software Interrupts (RST instructions):
RST 0 (0000H), RST 1 (0008H), RST 2 (0010H), RST 3 (0018H), RST 4 (0020H), RST 5 (0028H), RST 6 (0030H), RST 7 (0038H)

📝 Model Answer
Internal Architecture of 8086:

8086 is a 16-bit microprocessor with 20-bit address bus (1MB addressable memory). It has two independent units:

1. Bus Interface Unit (BIU):
Handles all bus operations. Contains:
  • Segment Registers: CS, DS, SS, ES (16-bit each)
  • Instruction Pointer (IP) – 16-bit
  • Instruction Queue – 6-byte FIFO prefetch queue
  • Address Adder: Physical Address = Segment × 10H + Offset

2. Execution Unit (EU):
Executes instructions decoded from queue. Contains:
  • General Purpose Registers: AX, BX, CX, DX (16-bit each, each split into high/low 8-bit)
  • Index Registers: SI, DI, BP, SP
  • ALU – 16-bit arithmetic and logic
  • Flags Register – 16-bit with 9 active flags
  • Instruction Decoder & Control Unit

Key Feature – Pipelining: BIU fetches next instruction while EU executes current, improving performance.

80286 Microprocessor Architecture:

80286 is a 16-bit processor with 24-bit address bus (16MB RAM, vs 1MB for 8086). It operates in two modes:

Block Diagram Units:

1. Bus Unit (BU): Manages external bus operations (address generation and data transfer). 24-bit physical address output.

2. Instruction Unit (IU): Fetches and decodes instructions from the prefetch queue. Holds 6-byte instruction queue.

3. Execution Unit (EU): Executes decoded instructions. Contains ALU, registers (AX, BX, CX, DX, SP, BP, SI, DI), and barrel shifter.

4. Address Unit (AU): Calculates linear addresses in protected mode. Contains segment descriptor cache, limit checker, and protection checker.

Operating Modes:
  • Real Mode: 1MB address space, compatible with 8086/8088
  • Protected Virtual Address Mode: Up to 1GB virtual per task, memory protection with privilege levels (0–3)

Write an 8085 assembly language program to generate a 1-second delay for a given crystal frequency.
Delay Programs 7 Marks 3× Repeated
▼
📅 All Occurrences

📝 Model Answer
1-Second Delay Program for 8085 (2 MHz Crystal):

Clock Period: Crystal = 2MHz → Operating freq = 1MHz → T-state = 1μs

Delay Calculation:
Inner loop: DCX D (6 T-states) + JNZ (10 T-states) = 16μs per iteration
For 1 second: Need 1,000,000 / 16 ≈ 62,500 iterations → Use nested loops

Program: 
; 1-Second Delay (Crystal = 2MHz, T = 1μs)
DELAY:
    MVI B, 07H      ; Outer loop count
OUTER:
    LXI D, FFFFh    ; Inner loop count (65535)
INNER:
    DCX D           ; Decrement DE pair (6 T-states)
    MOV A, E        ; Move E to A (4 T-states)
    ORA D           ; OR D with A (4 T-states)
    JNZ INNER       ; Jump if not zero (10 T-states)
    DCR B           ; Decrement B (4 T-states)
    JNZ OUTER       ; Jump if not zero (10 T-states)
    RET             ; Return (10 T-states)
Note: Adjust loop counts based on crystal frequency. For 1 MHz crystal, T-state = 2μs, so reduce counts by half.

Subroutine: A group of instructions that perform a specific task and can be called multiple times from different places in the main program. Saves code duplication.

CALL instruction: Pushes PC on stack, jumps to subroutine address.
RET instruction: Pops address from stack, returns to calling point.

Example – Delay Subroutine: 
; Main Program
    MVI A, 05H
    CALL DELAY      ; Call subroutine
    HLT

    MVI C, FFH  ; Load counter
LOOP:
    DCR C       ; Decrement C
    JNZ LOOP    ; Loop until C=0
    RET         ; Return to caller

Explain PUSH and POP instructions and concept of Stack in 8085.
Stack Operations3 Marks2× Repeated
▼
📅 All Occurrences

S2024Summer 2024 – Q.4(a)3 marks
📝 Model Answer
Stack: A LIFO (Last In First Out) data structure in memory. The Stack Pointer (SP) register points to the top of stack.

PUSH instruction: SP = SP – 2 (decremented by 2), then stores register pair content to [SP+1, SP].
Example: PUSH B → Pushes B (to SP+1) and C (to SP) onto stack.

POP instruction: Loads register pair from [SP, SP+1], then SP = SP + 2.
Example: POP H → Pops [SP] to L and [SP+1] to H.

Use: Preserving register values during subroutine calls.

📝 Model Answer
Segment Registers in 8086 (4 × 16-bit):

CS (Code Segment): Points to the segment containing the currently executing program code. Used with IP to form code address: CS × 10H + IP.

DS (Data Segment): Points to the segment containing program data (variables, arrays). Used with SI/DI/BX for data addressing.

SS (Stack Segment): Points to the stack area. Used with SP and BP. PUSH/POP operations use this segment.

ES (Extra Segment): Additional data segment. Used for string operations (MOVS, LODS, etc.) as destination segment.

Physical Address Calculation:
Physical Address = Segment Register × 10H + Offset
Example: CS=1000H, IP=0500H → PA = 10000H + 0500H = 10500H

Key Features: 32-bit data bus, 32-bit address bus (4GB addressing), 32-bit registers.

Segmentation in 8086:

8086 has a 20-bit address bus but only 16-bit registers. To address 1MB (2^20 = 1,048,576 locations), it uses segmentation.

Concept: Memory is divided into logical segments. Each segment can be up to 64KB (2^16).

Physical Address Formula:
Physical Address = Segment × 10H + Offset

Example:
CS = 2000H, IP = 0300H
PA = 20000H + 0300H = 20300H

4 Segment Registers:
CS (Code), DS (Data), SS (Stack), ES (Extra/String)

Each segment starts at a 16-byte (paragraph) boundary in physical memory.
