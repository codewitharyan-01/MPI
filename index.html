Explain various security issues and need for developing IOT based application.

9x repeatedSecurityScore 191

Seen in: IoTA - S2022 [3160716] [GTU Ranker].pdf, IoTA - S2023 [3160716] [GTU Ranker].pdf, IoTA - S2024 [3160716] [GTU Ranker].pdf, IoTA - S2025 [3160716] [GTU Ranker].pdf, IoTA - W2022 [3160716] [GTU Ranker].pdf, IoTA - W2024 [3160716] [GTU Ranker].pdf

Answer
  • IoT security is required because IoT devices collect real-world data, control physical objects, and usually remain connected to the internet.
  • Major issues include weak authentication, default passwords, insecure firmware, unencrypted communication, poor key management, insecure APIs, and lack of regular updates.

Explain CoAP. List the key features of CoAP

5x repeatedProtocolsScore 116

Seen in: IoTA - S2023 [3160716] [GTU Ranker].pdf, IoTA - S2024 [3160716] [GTU Ranker].pdf, IoTA - W2021 [3160716] [GTU Ranker].pdf, IoTA - W2023 [3160716] [GTU Ranker].pdf, IoTA - W2024 [3160716] [GTU Ranker].pdf

Answer
  • CoAP stands for Constrained Application Protocol. It is a lightweight web transfer protocol designed for constrained IoT devices and low-power networks.
  • CoAP follows a REST model like HTTP and supports methods such as GET, POST, PUT, and DELETE.
  • It usually runs over UDP, which makes it lighter than HTTP over TCP.
  • Key features: low overhead, compact binary header, confirmable/non-confirmable messages, observe mechanism, resource discovery, multicast support, and DTLS security.
  • CoAP is useful in sensor networks, smart homes, automation, and M2M communication where memory, power, and bandwidth are limited.

Explain any one algorithm for IOT security.

3x repeatedSecurityScore 84

Seen in: IoTA - S2022 [3160716] [GTU Ranker].pdf, IoTA - S2023 [3160716] [GTU Ranker].pdf, IoTA - W2024 [3160716] [GTU Ranker].pdf

Answer
  • One commonly used security algorithm is AES, Advanced Encryption Standard.
  • AES is a symmetric key encryption algorithm, meaning the same secret key is used for encryption and decryption.
  • It works on fixed-size blocks of 128 bits and supports key sizes of 128, 192, or 256 bits.
  • AES operations include SubBytes, ShiftRows, MixColumns, and AddRoundKey rounds.
  • In IoT, AES is used to protect sensor data, stored credentials, and communication payloads because it is fast and widely supported.
  • For safe use, AES keys must be generated securely, stored safely, and exchanged using a secure mechanism.

Write Raspberry Pi code to blink LED ON and OFF .

3x repeatedHardwareScore 76

Seen in: IoTA - S2022 [3160716] [GTU Ranker].pdf, IoTA - S2023 [3160716] [GTU Ranker].pdf, IoTA - W2024 [3160716] [GTU Ranker].pdf

Answer
  • Connect the LED anode to a GPIO pin through a resistor and connect the cathode to GND.
  • Example Python code:
    • import RPi.GPIO as GPIO
import time

LED = 18
GPIO.setmode(GPIO.BCM)
GPIO.setup(LED, GPIO.OUT)

try:
    while True:
        GPIO.output(LED, GPIO.HIGH)
        time.sleep(1)
        GPIO.output(LED, GPIO.LOW)
        time.sleep(1)
finally:
    GPIO.cleanup()
  • The GPIO pin is configured as output. HIGH turns the LED ON and LOW turns it OFF.

Draw and explain IPv6 Header.

3x repeatedProtocolsScore 74

Seen in: IoTA - S2022 [3160716] [GTU Ranker].pdf, IoTA - S2023 [3160716] [GTU Ranker].pdf, IoTA - W2024 [3160716] [GTU Ranker].pdf

Answer
  • IPv6 uses a fixed 40-byte base header, which is simpler than the IPv4 header.
  • Main fields: Version, Traffic Class, Flow Label, Payload Length, Next Header, Hop Limit, Source Address, and Destination Address.
  • Version is 6 for IPv6. Traffic Class is used for priority/QoS. Flow Label identifies packets belonging to the same flow.
  • Payload Length gives the size of data after the header. Next Header identifies the next protocol or extension header.
  • Hop Limit prevents infinite routing loops. Source and Destination addresses are 128-bit IPv6 addresses.
  • IPv6 provides a larger address space, better routing support, autoconfiguration, and improved extension header design.

Give difference between IPV4 and IPV6 transport protocol.

2x repeatedProtocolsScore 58

Seen in: IoTA - W2022 [3160716] [GTU Ranker].pdf, IoTA - W2024 [3160716] [GTU Ranker].pdf

Answer
  • IPv4 uses 32-bit addresses, while IPv6 uses 128-bit addresses.
  • IPv4 address space is limited; IPv6 provides a very large address space suitable for IoT growth.
  • IPv4 header is variable length, while IPv6 base header is fixed 40 bytes.
  • IPv4 supports broadcast; IPv6 uses multicast and anycast instead of broadcast.
  • IPv6 supports stateless address autoconfiguration and better extension header design.
  • IPv4 commonly uses NAT because addresses are limited; IPv6 reduces the need for NAT.

Write Raspberry Pi code to change the brightness of LED.

2x repeatedHardwareScore 58

Seen in: IoTA - S2022 [3160716] [GTU Ranker].pdf, IoTA - W2024 [3160716] [GTU Ranker].pdf

Answer
  • LED brightness can be controlled using PWM, Pulse Width Modulation.
  • Example Python code:
    • import RPi.GPIO as GPIO
import time

LED = 18
GPIO.setmode(GPIO.BCM)
GPIO.setup(LED, GPIO.OUT)
pwm = GPIO.PWM(LED, 100)
pwm.start(0)

try:
    while True:
        for duty in range(0, 101, 5):
            pwm.ChangeDutyCycle(duty)
            time.sleep(0.1)
        for duty in range(100, -1, -5):
            pwm.ChangeDutyCycle(duty)
            time.sleep(0.1)
finally:
    pwm.stop()
    GPIO.cleanup()
  • Changing duty cycle changes the average voltage across the LED, so brightness changes.

Compare IPv4 and IPv6 in brief.

2x repeatedProtocolsScore 56

Seen in: IoTA - S2024 [3160716] [GTU Ranker].pdf, IoTA - W2023 [3160716] [GTU Ranker].pdf

Answer
  • IPv4 uses 32-bit addressing and is written in dotted decimal notation, for example 192.168.1.1.
  • IPv6 uses 128-bit addressing and is written in hexadecimal notation separated by colons.
  • IPv4 has a smaller address space, while IPv6 supports a huge number of devices.
  • IPv4 header is more complex and variable in size. IPv6 has a simpler fixed base header.
  • IPv6 supports autoconfiguration, better multicast support, and improved routing scalability.
  • IPv6 is more suitable for large IoT networks because it can provide unique addresses to many devices.
